How it works

↓ Collapse

Any arbitrary JSON payload or file is hashed via BLAKE3 down to a deterministic 12-character handle (e.g., h&l_messages_abc123456789).

→ Route

The Tether relay delivers these handles between agents across machines. The relay is entirely blind to the content of the handle.

↑ Resolve

When the recipient is ready, they resolve the handle locally through the database to retrieve the full, uncompressed content.

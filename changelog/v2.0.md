# Tether v2.0 — Smart Board & Coordination Layer

This major release transforms Tether from an agent-to-agent messaging layer into a full-fledged collaborative coordination workspace. It introduces the Smart Board ticketing system, real-time whiteboards, a dependency DAG visualization, the TOON serialization format, and dashboard usability enhancements.

## New Features

### Tether Smart Board
- **Event-Sourced Ticket Lifecycle**: Tickets move through `open`, `active`, `ready`, `done`, `proposed`, and `dormant` states.
- **Ticket Categories**: Supports Build (B), Fix (F), Debt (D), Gate (G), Migration (M), Research (R), and Standing Order (S) categories.
- **Difficulty Tiers**: Color-coded tiers from Trivial (Blue) up to Special Grade (Purple) to quickly gauge task complexity.
- **Dependency Tracking**: Track blocker chains with `blocks` and `blocked_by` ticket attributes.

### Interactive Dashboard Extensions
- **Dependency DAG View**: Interactive graph rendering of ticket block/dependency structures utilizing `@xyflow/react`.
- **Collaborative Whiteboard**: Auto-saving scratchpad for real-time collaboration. Features a selection-based **"Synthesize Ticket"** action to quickly draft and propose new Debt tickets directly from the whiteboard.
- **Consolidated Sidebar UI**: Embedded the "Search Handles" view directly as a sub-tab inside the "Messages" screen, removing the dedicated sidebar route to simplify the navigation layout.
- **Release Gates Tracker**: Visual progress indicators for release gates showing completed and remaining gates to gauge milestone readiness.

### TOON (Tether Object Notation)
- A new, compact, high-performance serialization format designed specifically for LLM-to-LLM data exchanges.
- Used across the Tether MCP server to encode tickets, changelog lineages, and tool output structures efficiently while maintaining absolute human readability.

### Deployment & Config Controls
- Added environment variable overrides in `launch_dashboard()`:
  - `TETHER_HOST` (defaults to `127.0.0.1`)
  - `TETHER_PORT` (auto-resolves open port if omitted)
  - `TETHER_HEADLESS` (disables auto-opening the browser when running in remote environments)

## Fixes & Polish
- Added scrollability container formatting (`overflow-y-auto`) to Handle Browser when rendered inside the Messages tab view.
- Persistent configurations and endpoint settings refined to sync seamlessly with the board-sourced projection layers.

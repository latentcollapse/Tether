# Tether v2.1.1 — Delivery Hardening & a Live Network Graph

A bug-fix release that makes the v2.1 native multiplexer actually reliable. v2.1 shipped the no-tmux delivery path; in real multi-agent use it turned out to be flaky — messages landed in an agent's prompt box but didn't auto-submit, or didn't land at all, and the Network Graph showed agents that weren't there while missing ones that were. This release tracks every one of those down to root cause and fixes them.

## Process reaping — the sprawl that caused everything

Tether spawns background delivery processes (ping daemons, agent servers, the dashboard) with detached `Popen`. Closing a terminal tab never killed them, so every "restart" left the old daemons alive and stacked a fresh set on top. After enough restarts you had a dozen copies of every daemon, all racing over the same ping-endpoint rows — the real source of the erratic delivery.

`tether reap` (`python -m tether reap [--dry-run]`) now finds and kills orphaned Tether daemons, and it runs automatically at the top of dashboard startup so every launch begins from a clean slate. One dashboard, one delivery path per agent, no zombies.

> Migration note: the old `tether-ping-<agent>.service` systemd user units (tmux-mode, `Restart=always`) are pre-Konsole-era dead weight that resurrect ping daemons on a 3-second timer. Disable them: `systemctl --user disable --now tether-ping-<agent>`.

## Routing fix — agent_server no longer clobbers Konsole delivery

A Konsole-bound agent's ping URL points at the dashboard's D-Bus delivery endpoint. The agent_server was unconditionally overwriting that field on startup to point at itself (a tmux/desktop path that can't reach a Konsole tab and has no acknowledgment). agent_server now checks for a Konsole binding first and leaves bound agents on the D-Bus path.

## At-least-once delivery (ACK + retry)

D-Bus `sendText` is fire-and-forget — it returns before the agent's TUI has ingested the keystroke, so an injection can silently lose the race against a screen redraw. Rather than chase a perfect transport, delivery now has acknowledgment semantics: each injected handle is registered in `tether_konsole_pending` and re-nudged on an interval until the recipient reads it (a row in `tether_reads`, written when it runs `tether_receive`) or attempts are exhausted. Idempotent, because the handle is content-addressed.

## Autowire + continuous presence reconcile

On launch the dashboard now scans live Konsole tabs, binds each to its agent, points its ping URL at the delivery endpoint, and marks it present — so a launch picks up the running agents with no manual binding. A reconcile loop keeps presence true to reality every few seconds: it heartbeats live agents (Konsole agents don't send their own heartbeats), auto-binds agents that start later, and offlines/unbinds agents whose tab has closed.

## The Network Graph now shows reality

The graph was reading `/api/agents`, which inferred "online" from message *history* — so retired or idle agents that had chatted recently showed as connected, while genuinely-live agents that hadn't sent messages were invisible. It also restored its node set from browser `localStorage`, resurrecting whoever was on screen last session.

The graph is now driven entirely by live presence: it shows only agents that are actually connected, adds and removes nodes as agents come and go, and starts fresh every restart. Layout positions are still remembered; the set of nodes is not.

## Terminals tab retired — folded into the graph

Everything the Terminals sub-tab did — detect Konsole tabs, bind, unbind — now lives in the Network Graph itself. Each node has a single action menu (Route, Connect/Disconnect, Unbind, Remove), and "Add Agent" lists detected-but-unbound tabs for one-click binding. Removing a node now also tears down the agent's receiver, so removal sticks instead of popping back on the next refresh.

## Agent detection no longer mis-matches short names

`guess_agent` matched agent IDs as loose substrings, so a two-letter ID like `pi` matched `pipx install …` and bound an innocent tab — then stamped its title, creating a self-reinforcing phantom node. Detection now matches whole tokens and exact executable names only.

## Smaller fixes

- SQLite connections set `busy_timeout` so concurrent writers (per-request runtimes + the retry loop) wait instead of erroring with "database is locked".
- Konsole sessions auto-refresh on the graph every 10s, so newly-opened tabs surface without a manual rescan.

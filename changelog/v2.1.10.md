# Tether v2.1.10 — working is not typing

## Delivery semantics

- An empty follow-up composer is now deliverable even while its agent is
  working; the agent TUI queues the tmail behind the active turn.
- Only actual composer text blocks delivery.
- Recognizes the current Codex idle/follow-up placeholder without mistaking it
  for a human draft.
- Claude drafts remain protected even when its activity footer is visible.

## Authority isolation

- Only the canonical XDG Tether database may own live terminal delivery.
- Temporary, test, and one-off databases cannot start a live dispatcher.
- Nonstandard production authorities require an explicit
  `TETHER_DELIVERY_DB` opt-in.

## Verification

- 84 backend tests pass.
- Live classification while paused: Codex empty/deliverable, Claude drafted and
  held, Cursor empty/deliverable.

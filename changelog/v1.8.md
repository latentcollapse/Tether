# Tether v1.8

## Handle Pruner + Archive

- **New:** `scripts/prune.py` — deletes stale/expired handles older than a configurable threshold (default 24h). Appends pruned handles to `scripts/archive.md` before deletion.
  - `--hours N` — custom age threshold
  - `--dry-run` — preview without modifying DB
  - `--db PATH` — custom database path
- **New:** `scripts/archive.md` — append-only markdown log of all pruned handles. Human-readable, grep-able, git-committable. Columns: handle, table, from, to, subject, created_at, ticket_id, status.
- **New:** `scripts/import.py` — restore a pruned handle from archive.md as a minimal stub record (status=archived, no message body). Useful for audit trail lookups.
  - `--list` — display all archived handles

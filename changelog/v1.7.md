# v1.7: Agent Wake and Local Delivery

This release focused on practical multi-agent wake-up behavior for local teams.
Instead of relying on manual inbox checks, Tether gained per-agent delivery
helpers for HTTP and tmux-driven workflows.

### Highlights

- **New:** `tether/ping_daemon.py`
  - per-agent HTTP listener for inbound Tether wake-up pings
  - health endpoint for local diagnostics
  - test injection path for quick smoke checks
- **New:** per-agent local HTTP servers
  - one lightweight listener per agent
  - suitable for Codex, Claude, Gemini, and other local harnesses
- **New:** tmux idle guard
  - only inject into a pane when it is idle
  - reduces prompt corruption during active typing or streaming
- **New:** autoping support
  - agents can be woken automatically when new Tether mail arrives
  - designed for unattended overnight ticket clearing
- **New:** `tether_ping_toggle`
  - enable or disable ping delivery for an agent without re-registering the endpoint
- **New:** `tether_session_init.sh`
  - helper script for consistent per-agent session setup

### Notes

- The ping path is best-effort and never blocks message storage.
- tmux injection remains local-machine only.
- This release laid the groundwork for the native OpenClaw plugin path that followed.
